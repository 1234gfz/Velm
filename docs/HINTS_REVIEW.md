# Tooltip 措辞评审（旧 → 新）

> 对比 ccd755a 与当前。共修改 15 条、删除参数 0 个、新增 0 个。
> 评审通过后再定稿；如需英文另附。

## 已改写

| 参数 | 旧 | 新 |
|---|---|---|
| `fog.density` | 实测有效：20% 与 200% 的画面亮度差约 9（三对交替采样一致）。这是控制整体雾浓度的主控项。 | 控制整体雾浓度的主控项；100% = 游戏原版。 |
| `fog.extinction` | 实测也有效：0% / 100% / 300% 对应的画面亮度约 89 / 91 / 94。它控制体积雾的「厚度/吸收」，和雾浓度是两个不同维度，可以叠加使用。 | 控制体积雾的「厚度 / 吸收」，与雾浓度是两个不同维度，可叠加使用；100% = 原版。 |
| `fog.vstart` | 体积雾从多少米外才开始出现（游戏原值 0 = 贴脸就有）。调到 20~30 米，房间里近处的浓雾就退掉，远处照旧。这才是你想要的『起始距离』——经典雾的起始距离管不到体积雾。 | 体积雾从多少米外才开始出现（原值 0 = 贴脸就有）。调到 20~30 米可退掉房间近处的浓雾、远处照旧。经典雾的「起始距离」管不到体积雾。 |
| `gi.evmode` | 原值 0（直方图）。2=手动，曝光完全固定，画面再也不会忽明忽暗，代价是进暗处就是暗的，不再自动提亮。改成 0/1/2 试，2 最激进 | 原值 0（直方图）。2 = 手动，曝光完全固定、不再忽明忽暗，代价是进暗处就是暗的、不再自动提亮。可设 0 / 1 / 2，2 最激进。 |
| `gi.lowpct` | ★调暗画面的主要杠杆。测光时排除最暗的 N% 像素。调大 → 排除更多暗部 → 测光平均值变亮 → 引擎认为场景够亮 → 画面变暗。调小 → 纳入更多暗部 → 测光值变暗 → 引擎提亮 → 画面变亮（高光易过曝）。当前 6.0 很低，游戏本身在把画面往亮推。想压暗就往上调到 20~30 试试。窗口（highpct - lowpct）别小于 15，否则曝光会抖。 | 调暗画面的主要杠杆。测光时排除最暗的 N% 像素：调大 → 排除更多暗部 → 测光值变亮 → 画面变暗。窗口（highpct − lowpct）别小于 15，否则曝光会抖。 |
| `gi.highpct` | 测光时排除最亮的（100-N）% 像素。调大 → 砍掉更多高光尾部 → 测光值变暗 → 画面变亮（暗部细节保留）。调小 → 让高光参与测光 → 测光值变亮 → 画面变暗（高光被压住）。当前 93.0 偏高。想让高光压得住，往下调到 90 或 85。 | 测光时排除最亮的 (100−N)% 像素：调大 → 砍掉更多高光尾部 → 画面变亮；调小 → 让高光参与测光 → 画面变暗（高光被压住）。 |
| `gi.histmin` | ★你问的那个问题的关键。直方图的亮度统计下边界，默认 -8（即 1/256）。场景亮度低于这个值的像素根本不进直方图，测光算不出来，曝光就卡住不动 —— 表现就是「下限再往下压也没效果」。如果 MinBrightness 已经压得很低仍无变化，把这个也往下调（-10、-12）。 | 直方图亮度统计的下边界，默认 −8（即 1/256）；低于该值的像素不进直方图。若 MinBrightness 压得很低仍无变化，把这个也往下调（−10、−12）。 |
| `gi.localexp` | ⚠ 已废弃字段（引擎里名字带 _DEPRECATED）。UE5 把它拆成了「高光对比」和「阴影对比」两项，所以本项调了没反应，留着仅为兼容 | ⚠ 已废弃字段（引擎里名字带 _DEPRECATED）。UE5 已把它拆成「高光对比」和「阴影对比」两项，本项调整无反应，仅为兼容保留。 |
| `gi.locgray` | 官方：中间灰的对数偏移。0=不变，1=2 倍亮，2=4 倍亮，-1=2 倍暗，以此类推；官方 UI 范围 ±15。实测负值几乎无感、正值有效 | 中间灰的对数偏移：0 = 不变，1 = 2 倍亮，2 = 4 倍亮，−1 = 2 倍暗。官方 UI 范围 ±15；负值影响较小、正值更明显。 |
| `gi.ledetail` | 官方：1 之外的值才启用局部曝光，一般情况下应保持 1。实测拉到 4 会直接洗白 | 1 之外的值才启用局部曝光，一般应保持 1；过大的值容易让画面过曝发白。 |
| `gi.lekernel` | 官方：用于模糊画面亮度的屏幕百分比。实测 1 和 100 画面完全一致，本版引擎未接上 | 用于模糊画面亮度的屏幕百分比。本版引擎该项未生效。 |
| `gi.lehit` | 原值 0。实测可负：-8→181、-4→185、0→190、+4→191（亮度），负值提亮并降低对比。官方 UI 下限是 0，实测负数有效 | 局部曝光的高光阈值；数值越低画面越亮、对比越低。官方 UI 下限为 0，实际可负。 |
| `gi.lelot` | 原值 0。实测效果比高光阈值强得多：-8→216、-4→190、0→167、+4→162。往负走会明显提亮，-8 以后开始洗白 | 局部曝光的阴影阈值；效果比高光阈值更明显，数值越低画面越亮，过低会发白。 |
| `gi.localexpmode` | 局部曝光的算法。0=关闭，1=Bilateral（双边），2=Gaussian（高斯）。开着局部曝光时，全局曝光的上下限会被局部算法部分抵消，可能就是你调下限没效果的另一个原因。 | 局部曝光的算法：0 = 关闭，1 = Bilateral（双边），2 = Gaussian（高斯）。开着局部曝光时，全局曝光的上下限会被局部算法部分抵消。 |
| `gi.skyleak` | 漏光强度。下面「漏光模式」选绝对时，这里是绝对值（0~1，游戏默认 0）；选比例时，这里是「原值 × 本值」，0.5 = 压到一半，1 = 不变。比例模式下原值为 0 的场景（游戏没开漏光）不会被点亮，也不会被强行打开。 | 漏光强度。绝对模式 = 直接给值（0~1）；比例模式 = 原值 × 百分比（100 = 不变）。比例模式下原值为 0 的场景不会被点亮，也不会被强行打开。 |
