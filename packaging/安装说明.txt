Velm（小维）· 影之刃零 画面调参模组 —— 安装说明 / Install Guide
================================================================

【这是什么 / What is this】
解压后得到一个 Velm\ 文件夹，里面：
  Velm\PBZModManager.exe   ← 安装器（双击它）
  Velm\安装说明.txt
  Velm\payload\            ← 要装进游戏的模组和 UE4SS（不用你手动放）
After unzipping you get a Velm\ folder: double-click PBZModManager.exe; the stuff under payload\ is installed into the game automatically — you don't place anything by hand.

【一键安装 / Quick install】
1. 关闭游戏 / Close the game.
2. 双击 Velm\PBZModManager.exe / Double-click Velm\PBZModManager.exe.
   （这个 Velm 文件夹放哪都行：桌面、D:\Tools 都行，不必放进游戏目录。You can keep the Velm folder anywhere.）
3. 点「自动检测」找到游戏目录；「使用自带 UE4SS」默认已勾选。
4. 点「安装 / 修复」。进游戏按 F8 打开面板；面板右上角可切换 中文 / English。

【手动安装 / Manual install（不想用管理器时）】
把 payload 里的东西拷进游戏：
1. payload\ue4ss 文件夹 和 payload\dwmapi.dll  →  <游戏>\PBZ\platform\steam\
2. payload\PBZFog 文件夹                        →  <游戏>\PBZ\platform\steam\ue4ss\Mods\
3. 在 …\ue4ss\Mods\mods.txt 里加一行：PBZFog : 1

【卸载 / Uninstall】
管理器点「卸载」；或手动删除 Mods\PBZFog 目录，并从 mods.txt 去掉 PBZFog 那行。

【注意 / Notes】
- 若游戏目录已有其它注入代理（version.dll / dxgi.dll 等），管理器会提示冲突，确认共存再继续。
- 只读写单机画面参数，不含游戏资源、不涉及破解。MIT 许可。
  Single-player visual params only; no game assets, no cracking. MIT license.

【更新 / Update】
管理器里点「检查更新」（国内可在旁边填代理 http://127.0.0.1:7897）；有新版时到发布页下载新包覆盖安装。
